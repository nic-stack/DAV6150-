# DAV 6150 Datasets

This repository holds raw datasets from my **DAV 6150 (Data Science)** coursework at Yeshiva University's Katz School.

👉 **The projects themselves are in [DAV6150-Data-Science-Portfolio](https://github.com/nic-stack/DAV6150-Data-Science-Portfolio)**: 11 end-to-end machine learning projects with notebooks, READMEs and results.

| File | Used in |
|------|---------|
| `M3_Data.csv` | Data Cleaning: Wine Sales |
| `M4_Data.csv` | Feature Selection and Neural Networks: Online News Popularity |
| `Project1_Data.csv` | Regression: NYS Student Dropouts |
| `M7_Data.csv` | Logistic Regression and KNN/SVM: Insurance Cross-Sell |
| `Project2_Data.csv`, `Project2_Data_Labels.csv` | Clustering + SVM: Online Shoppers |
| `M11_Data.csv` | Decision Trees/Random Forests and Gradient Boosting: NYS Graduation Outcomes |
